## Что ROOT выбирает вместе с запуском

- Вместе берутся штатный разговорный realtime loop, camera question tool и один MovementManager с breathing/poses/dances/speech wobble. **Модель/голос меняются**: не наша9B/Whisper/Piper; русское качество, latency/AEC и эксплуатационная устойчивость на этом стенде пока UNVERIFIED. Камера по tool call не равна постоянной semantic scene memory; локальный случайный idle не равен постоянным LLM decisions.
- **Внешняя обработка:** audio stream и camera-tool JPEG покидают LAN и идут в HF; отдельный свежий instance/cache/profile, memoryOFF, никаких перенесённых личных memories/credentials. Recipe запускает deployed mode с пустым HF_TOKEN. По уже прочитанным официальным README/code отдельный paid API key/new account не требуется; actual allocation/quota/network этого робота **UNKNOWN**. Reject/недоступность allocator — конкретный внешний blocker с HTTP status/typed class, не повод создавать account/покупать key/менять endpoint.
- **Ownership/STOP меняются:** App напрямую использует SDK и становится единственным media/motion front door. Прежний Hub motor policy и `scripts/companion voice microphone-off` **не управляют App**. App UI micOFF может оставить breathing; полный STOP — normal App stop/Ctrl-C/SIGINT только exact owned App process, подтверждённые media/movement thread reap, wobble/tracking off и factory known idle. Это должно быть явно передано пользователю до оставления App ON.
- PC9B/Whisper/Piper/Hub, исходники/модели/private config/+2dB и exact S6 backups остаются установлены/сохранены для rollback. Существующий operator camera/Piper workflow временно не вызывается поверх App. +2dB локального Piper сохранён в backup, но **не обещается идентичная громкость другого App audio path**.
