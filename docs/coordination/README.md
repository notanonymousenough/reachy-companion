# Требования и история поставки

Актуальный локальный вход — [README](../../README.md) и [STATUS](../STATUS.md).

- `REQUIREMENTS.md` и `design-2026-10-17.md` сохраняют полный продуктовый scope.
- `EXPERIENCE-RESET-2026-10-25.md` описывает последний сохранённый продуктовый курс.
- `PROJECT.md`, `TECH-STATUS*.md`, runtime baseline и R/U/T-отчёты — датированная
  история. Слово CURRENT внутри них относится к времени соответствующей записи.
- Старые PID, разрешения и сроки не запускают новых действий. Source PASS,
  pipeline PASS и пользовательская/физическая приёмка различаются.

Ссылки в исторических отчётах на корневые R/U/S/evidence-каталоги и персональные
пути — исторические ссылки. Локальные материалы сохранены во внешнем архиве;
часть прежних персональных путей отсутствовала уже до очистки. Основной код и
автоматические проверки больше не зависят от этих каталогов. Старые Git pins
для проверки исторических overlays сохраняются в полной истории репозитория.
