## Actual request → strict decode → declared render → неизменный validator

Normal `Pipeline.answer(... alice_short=True, reply_constraints=None)` строит прежнюю persona/history/interruption/user messages, добавляет объявление typed output contract и отправляет **один** `model=current9B,messages,temperature=current,max_tokens=current,stream=false,response_format=json_schema` на existing base `/v1` + `/chat/completions`. Это явная смена только Alice generation route, допускаемая после same-model gate; tool/camera/native/human routes не переключаются. [LM Studio primary docs](https://lmstudio.ai/docs/developer/openai-compat/structured-output) подтверждают этот API и grammar sampling для GGUF, но не доказывают текущую runtime совместимость.

Schema: exact object `{words: string[1..10], terminal: enum[".","?","!"]}`, additionalProperties=false; word pattern `^[A-Za-zА-Яа-яЁё0-9]{1,112}[,;:]?$`. Допускает обычные длинные русские слова, цифры и внутренние запятые/двоеточия/semicolon; нет маленького искусственного словаря. Не разрешает style tags/переносы/внутренние sentence terminators. Renderer **ровно** `' '.join(words)+terminal` — заранее объявленный contract, не исправление/обрезка free text.

Ответ ограничен1MiB, проверяются current model/один index0/matching terminal. Только finish_reason=stop → bounded strict JSON (duplicate keys/NaN/extra fields/type/count/pattern/terminal rejected) → renderer → **дословно неизменный `validate_alice_phrase`** → существующие prepare/segments/TTS/history. `length` не озвучивается. Общие≤120 spoken chars, body≤10 regex words, punctuation once и normalized wake-name exclusion остаются неизменными final guards. Schema **не кодирует глобальную сумму chars и wake exclusions**; host их обязательно отклоняет, не repair/retry. Semantic completeness/factual accuracy grammar не гарантирует.

Transport — существующие `Pipeline.lock` и `self.http`, без зависимостей/нового owner/framework. Перед POST ставится process-local UNKNOWN latch; лишь matching terminal stop/length снимает его. Transport/непроверенный envelope → следующий Alice dispatch блокирован без POST до operator reconciliation. Старый legacy brains не имел такого guard; он не предполагается внедрённым. Обычный human/default-false и explicit old reply_constraints paths сохранены; сам validator/HTTP422+503 handlers/STT/STOP/TTS/PCM не менялись.
