# Camera semantic observer: source outcome

`r42/semantic_observer.py` и `tests/test_semantic_observer.py`. Agent/sensory_bridge/snapshot_vision/manifest не менялись. Hardware0/remote0. Реальная SDK source-проверка TL: [sdk-camera.json](../../R53-loop/baseline/sdk-camera.json), SDK1.11.0/GStreamer1.26.2. Код готов к интеграции; живой camera/model proof ещё требуется.

**Возраст относится к source presentation timestamp, не к моменту аппаратной экспозиции.** IPC SDK использует daemon-owned camera; `videorate(drop-only=True)` ограничивает feed, consumer appsink хранит один latest buffer. Observer открывает только существующий IPC consumer, без MediaManager, audio и нового физического camera source. [Официальный SDK1.11 producer](https://raw.githubusercontent.com/pollen-robotics/reachy_mini/v1.11.0/src/reachy_mini/media/media_server.py).

GStreamer unixfdsink переводит PTS+SEGMENT+producer base time в system monotonic и добавляет negotiated pipeline latency; unixfdsrc переводит обратно в consumer running time. Observer восстанавливает presentation time через `sample.segment.to_running_time(PTS)+consumer base_time` и пару local monotonic/GstClock readings, сохраняя интервал погрешности чтения clock. Проверяется MONOTONIC clock; PTS0/NONE, регрессия, отсутствие двух продвинувшихся samples и просрочка отвергаются. [unixfdsink1.26.2](https://raw.githubusercontent.com/GStreamer/gstreamer/1.26.2/subprojects/gst-plugins-bad/gst/unixfd/gstunixfdsink.c), [unixfdsrc1.26.2](https://raw.githubusercontent.com/GStreamer/gstreamer/1.26.2/subprojects/gst-plugins-bad/gst/unixfd/gstunixfdsrc.c).

Результат содержит `source_presentation_age_s={lower,upper}`, отдельно `physical_exposure_age_s={lower,upper:null}`, `source_capture_time_verified=false`, `source_progress_verified=true`, PTS/progress/plugin metadata и срок от **earliest source presentation time**, не от завершения VLM. У модели/компактного observation остаётся явная фраза об unverified exposure age. Известный presentation interval позволяет полезное описание реального полученного кадра без обещания точного текущего exposure. SDK `find_plugin('unixfd')==None` до загрузки не трактуется как отсутствие unixfd; версия берётся у загруженной factory `unixfdsrc` внутри camera child.

`SemanticObserver(config, authority, publish, model_available=...)` создаётся только при явном product opt-in. TL подаёт trusted `(binding,enabled,privacy)` с реальными boot/MIC/policy/intent/mode и разрешением камеры, bounded `publish=loop.publish` и **обязательный model-admission hook**. Hook учитывает actual foreground/sound/VLM и неизвестную занятость общего backend; он не должен игнорировать параллельного владельца. Сам observer гарантирует одного своего child/запрос, но не объявляет эксклюзивность всего PC model сервера. До широкой интеграции TL обеспечивает согласованный shared admission для отправляющих в один backend путей.

Регулярный `advance()` не ждёт capture/inference. Один worker/child читает два progressing кадра, закрывает camera pipeline в NULL, затем сообщает `ready_for_model`; parent повторно проверяет controls/TTL/model slot и только после этого отправляет `go`. VLM — текущий уже загруженный vision-capable instance локального LMStudio, native `/api/v1/chat`, store=false/integrations=[], без Robot bearer; новые модели не загружаются. Pixels существуют только в RAM child/локального PC request, в stdout/файлы не выводятся. Publication происходит после terminal child/reap, повторной authority/TTL проверки; compact observation имеет kind `vision.semantic` и source `shared-camera-source-presentation-pts`.

OFF/privacy/смена binding/expiry отменяют child, terminate→kill при необходимости, но lane остаётся занят до реального reap. При отмене после parent model grant и без terminal acknowledgement ставится `model_execution_unknown`: повторного inference нет. Unknown нельзя сбрасывать только новым ON/timeout; требуется известное завершение backend в штатном пути. `close()` отзывает admission; caller продолжает `advance()` до terminal busy=false. Никаких новых outputs/permissions от observer нет.

Default cadence 8с, TTL15с, model socket timeout8с, одна работа без backlog. Модель может описать предметы/цвета одного кадра; изменение сцены требует сравнения наблюдений в следующем reducer, оно не выдумывается из одного снимка. При интеграции проверить реальное продвижение PTS, clock mapping/возраст, закрытие IPC, actual caption, источник action и совместную работу со звуком/речью. Тесты проверяют математику interval/expiry, source-vs-exposure uncertainty, controls/reaping, native model envelope и отсутствие pixels в stdout на синтетических источниках; это не live proof.
