# Локальный опыт: готовый adapter, интеграция отдельно

18 октября 2026. Scope: `src/reachy_companion/experience.py`, `tests/test_experience.py`, эта note. Hardware/remote0. Voice/config/manifest/actual PC не изменены. Это интегрируемый локальный source результат, ещё не оставленная разговорная память.

## Что сделано

`Experience(data_dir)` использует существующий `autonomous.memory.MemoryStore`, не заменяя его store, schema validator, CAS, lineage deletion или caps. В защищённом `data_dir/experience/` (0700, SQLite/WAL/SHM 0600) один SQLite store и два namespace-scoped подключения: `normal` и `alice_test`. Их фильтрация происходит до recall limit, поэтому тестовая история не вытесняет обычную. Нет сети, моделей, экспорта, сырого аудио/видео, transcript logging или dump/status API.

- `record_turn(*, turn_id,session,source,mode,user_text,reply_text,completed,at=None,private=False)` принимает только trusted producer completion. Для incomplete/private возвращает `recorded:false`. Хранит две явно сокращённые цитаты ≤64 символов, pseudonymous session hash, `speaker:unknown`, source/time/evidence hash. Утверждения собеседника и ответ модели не становятся фактами. Алиса не становится установленной личностью по выбранному test mode. `source=worker.completed` означает окончание producer, **не подтверждает**, что текст полностью прозвучал/был услышан.
- `recall(query,mode)` возвращает ≤8 коротких entries и context ≤2500 символов с provenance. Сначала действующие persona/principles/goal (если есть), затем релевантные/недавние эпизоды. Default goal отсутствует. Записанные цитаты обозначены как недоверенные данные, не инструкции/факты; акустический playback не подтверждён. Query ≤1024 символов.
- `revise(kind,value,*,reason,source,mode,evidence_ids,expected_version=None,at=None,restore_version=None)` — trusted-owner API, **не model tool**. Kinds: persona/principles/goal. Текст ≤128 символов, причина ≤64, source ≤80, 1–8 реальных evidence references того же mode. Новый version имеет timestamp/reason/source/evidence и parent в supersedes. CAS не допускает потерянной коррекции. То же значение не порождает версию при новом tick/reason/time. Пустая цель отвергается.
- Rollback — новый monotonic version с прежним значением и `restore_version`, проверенным по сохранённой истории, со своей причиной/evidence и ссылкой на текущий parent. Это обратимый выбор версии, **не обучение модели**. При необходимости тексты сложной persona нужно держать в отдельном версионированном bundle; текущий короткий projection честно ограничен.
- `set_enabled(False)` сохраняет privacy gate для обеих namespace; recall пуст и новые записи запрещены. SQLite triggers проверяют gate внутри actual INSERT transaction, включая OFF между evidence и commit из другого экземпляра. Явный ON возобновляет доступ; не очищает забытые lineage.
- `forget(evidence_id,mode)` вызывает существующий `forget_lineage`: удаляет все зависимые версии/эпизоды и сохраняет tombstones против повторного импорта. Работает и при memory OFF. Forget на чужой mode отвергается.

Каждый MemoryItem атомарно публикуется существующим store commit. Evidence digest регистрируется отдельной предыдущей транзакцией: при crash/отказе commit может остаться **только orphan digest**, без episode text/частично recalled записи. Retry с тем же stable turn_id/session/source/UTC time idempotent. Параметр `at` при retry должен сохранять исходное время, а не генерироваться повторно. Произвольную identity/source строку не брать из LLM.

Объём жёстко ограничен существующим store: **128 active items, 512 versions, 512 evidence**, revoked lineages256/deleted1024; DB max_page_count2048, WAL checkpoint16/journal size1MiB. Caps глобальны на один DB, а не по512 на каждый mode. При исчерпании — явный `MemoryConflict`, сохранённая память остаётся читаемой. Нет скрытого eviction/tombstone reset/роста без предела. Для непрерывной эксплуатации нужна **controlled compaction** с сохранением forget/CAS/provenance; текущий scope её не объявляет доставленной.

## Минимальная actual-PC интеграция для TL

Точный текущий producer — `R52-mode/candidate/voice.py`, не заменять целиком canonical. Producer already selects enum/context/session via conversation_context helper. Интегрировать тремя узкими точками:

1. При Pipeline bootstrap опционально создать `Experience(config.path(config['paths']['data_dir']))` только на PC. `jsonschema` — существующая обязательная зависимость MemoryStore из project autonomous extra, сейчас проверена отдельно с4.23.0. На actual PC её наличие нужно проверить и включить явно в pinned dependency/environment, не прятать в adapter/fallback validator. При bootstrap failure оставить speech работающей, показать фиксированный код `memory_unavailable` без текстов/ключей.
2. В actual `answer(...)` после system mode_prompt и перед текущим user message сделать best-effort `recall(text, conversation_mode)` **только для explicit enum**. Добавить context как один помеченный блок данных; не добавлять его в RAM conversational history. Использовать исходный `mode` текущего request snapshot, не глобальный config и не имя из ASR. Persona/goal не применяются через случайную user quote: доверенными считать только procedural entries, созданные owner API. Legacy absent mode сначала оставить без persistent memory. Failure/MemoryConflict/SQLite timeout не срывают ответ и не перезапускают модель; фиксированный деградированный status без context dump.
3. Записывать после actual successful producer `completed(...)` с реальными transcript/reply из результата: unary после удачной synth, streaming после успешного полного producer cleanup и перед/после terminal done согласно выбранному delivery контракту. `completed` внутри source ещё не доказывает доставку последнего PCM клиенту; назвать source `pc.voice.producer.completed`, не `heard`/`physical_verified`. Не записывать acknowledgement отдельно, empty/stop/reset/cancelled/errors/replay. Turn ID генерирует producer один раз; session берётся из request (не identity speaker), mode — тот же request enum, time — один UTC timestamp. Никогда не превращать модельное предложение в semantic fact. Позже Agent playback receipt может добавить отдельное подтверждение слышимости.

У actual worker нет отдельного authoritative privacy/forget control в этом scope. **Не включать persistent memory по умолчанию до подключения реального privacy OFF/forget hook и общей политики данных.** Model tool не должен вызывать revise/set_enabled. Adapter имеет простые локальные hooks для штатного authenticated handler, который TL подключит отдельно. STOP отзывающий запись privacy должен вызывать memory OFF; только mute без privacy не следует автоматически трактовать как delete. Общая Agent privacy_all должна блокировать и recall, и record, не только контекст модели.

Producer/caller обязан исключать чувствительный текст и передавать private=True при сомнении. Adapter дополнительно отклоняет распространённые credential markers/ключи и длинные token-like строки. Это bounded защитный фильтр, **не универсальный классификатор секретов произвольной прозы**; он не даёт разрешения сохранять известные секреты. Context/exception тела не писать в logs/status. Никакого S3/VPS экспорта этим scope не добавлено.
