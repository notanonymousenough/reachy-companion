# Состояние Reachy Companion

Локальный срез **30 октября 2026**. В этой работе не выполнялись SSH, управление
роботом/Hub/PC, загрузка моделей или развёртывание. Состояние оборудования сегодня
не устанавливалось. Полный scope сохраняется в [требованиях](coordination/REQUIREMENTS.md).

| Область | Сохранённое состояние | Открыто |
|---|---|---|

## Локальное согласование

- В R42 сохранён весь текущий код, включая три прежде неучтённых модуля.
  Manifest v11 закрепляет 34 файла. Исторические provenance-поля оставлены
  историческими; текущую идентичность задаёт `files`. Hardware acceptance false.
- Реестр `code_identity.MODULES` дополнен девятью существующими верхнеуровневыми
  модулями. До исправления строгая генерация worker manifest падала на текущем
  дереве; строгая проверка состава и происхождения сохранена.
- R15/R20/S4/R52 fixtures перенесены в Git; абсолютный потерянный путь R15 удалён.
  R15 восстановлен по четырём историческим SHA256, R52 prompt заменён синтетикой.
- Исправлено локально воспроизведённое зависание SIGTERM/SIGINT в двух session
  entrypoints: signal handler теперь ставит простой terminal flag без Event lock;
  обычный control STOP по-прежнему использует Event. Предикат остановки видит
  сигнал сразу, bounded loop завершает прежний cleanup. Регрессия проверяет
  настоящий сигнал при занятом внутреннем condition lock в отдельном процессе.
- Основной Agent, R42, autonomous runtime и device lock-файлы сохранены;
  альтернативные возможности не удалялись. Legacy bootstrap остаются отключёнными:
  их callers и гарантии отказа ещё проверяются тестами.
- Архивы экспериментов и прежние сборки вынесены из checkout с резервной копией.
  Конфиги установки и `secrets/` сохранены локально и исключены из Git.

Финальная локальная проверка: **1592 unittest cases, 0 failures/errors, 26 явных
пропусков** в отдельном чистом клоне; JavaScript панели, build, отдельная установка
wheel, R42 и Git connectivity проходят. Причины пропусков и проверенный commit
зафиксированы в [машинном результате](validation-2026-10-30.json).
