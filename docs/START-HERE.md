# Reachy Companion: начать здесь

Актуальный локальный срез — **30 октября 2026**, без обращения к устройствам.

1. [README](../README.md): среда, тесты, структура и ограничения запуска.
2. [STATUS](STATUS.md): что реализовано, что подтверждено и что остаётся открытым.
3. [Очистка](cleanup-2026-10-30.md): изменения checkout и восстановление архивов.
4. [Требования](coordination/REQUIREMENTS.md): полный целевой scope.
5. [PROJECT](coordination/PROJECT.md): датированная история продуктовой поставки.

Документы `coordination/`, старые runbook и receipts сохраняются как история.
Указанные в них «CURRENT», «активный», разрешения, PID и сроки относятся к датам
записей и не подтверждают состояние устройств сегодня. Приоритет локальной
настройки и проверок задают README и STATUS. Аппаратные действия требуют
отдельной задачи; локальная очистка не развёртывает код.
