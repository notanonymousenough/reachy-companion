# Автономный Reachy Mini: спецификация для реализации

Дата исследования: 9 октября 2026. Ревизия проекта/контрактов: 1.1 (второй технический проход). Статус: проект, не развёртывание. Результат — поведенческая симуляция непрерывности, личности и внутреннего состояния; наличие сознания или субъективного опыта не утверждается.

## Принятое решение

Hub владеет непрерывным когнитивным циклом и разрешением действий. На каждой завершённой итерации вызывается быстрая LLM, даже если решение — спокойно ждать. ПК обновляет сенсорные кэши, обслуживает модели и выполняет ограниченные фоновые задачи. Медленные задачи не блокируют последующие решения. Собственный небольшой оркестратор отвечает за причинность, deadlines, память и полномочия; Hermes или OpenClaw можно подключить как отдельного исполнителя исследовательских задач. Их агентный цикл не заменяет цикл робота.

Начальная цель — примерно одна итерация в секунду, один активный быстрый запрос; это гипотеза для измерения, а не обещание скорости. При конкуренции частота уменьшается, но тишина сама по себе никогда не отменяет LLM-запрос. Остановка микрофона, звука и движения исполняется независимо от LLM. Если модель реально недоступна, решения не подделываются: фиксируется разрыв когнитивного цикла, работает только безопасное управление и ограниченные попытки восстановления.

Для RTX 5070 нельзя заранее принять одновременную полную GPU-загрузку 12B Q6, длинного KV-cache, STT и отдельной VLM. Рекомендуемый первый профиль: быстрая 0,6B на CPU ПК либо небольшая GPU-резиденция после замера, основная 12B Q4 с коротким контекстом, одна STT-задача, YAMNet и TTS на CPU. Q6 — альтернативный профиль с CPU-offload и/или STT на CPU. До проверки реального GGUF и runtime сохраняется возможность использовать уже работающую Qwen.

## Неподтверждённое перед реализацией

Чтение GPU-метрик через SSH к ПК и версии SDK через существующий hub было предпринято, но закончилось сетевыми таймаутами. Поэтому свободная VRAM, локальные SHA256/метаданные GGUF, версия runtime и фактические значения IMU/servo telemetry **не измерены**. Публичные источники подтверждают модельную семью и некоторые API, но не локальную совместимость. Эти проверки — ворота этапа 0; неизвестное не скрыто расчётами.

Адреса S3/VPS и ключи не заданы; внешняя отправка по умолчанию выключена. IP, локальные конфиги и secrets не включены в документы. Службы, модели, микрофон и движение в ходе проектирования не менялись; inference-запросы и новые исполнительные инструменты робота не запускались.
