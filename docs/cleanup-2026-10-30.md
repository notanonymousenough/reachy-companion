# Локальная очистка — 30 октября 2026

## Сохранность

Работа выполнена в `codex/repository-cleanup`, без deploy, SSH, камер, аудиоустройств
и живых моделей. До очистки сохранены tar.gz всей рабочей папки без `.git` и
кэшей Python, исходный tracked diff, индекс Git и перечень untracked-файлов.
Полная Git-история сохранена на месте; старые commits не переписывались.
`git gc --no-prune` упаковал историю без pruning: `.git` уменьшился примерно с
1,7 ГБ до 167 МБ. Finder metadata в `.git/refs` мешала `git fsck` и удалена;
10 незавершённых `tmp_obj_*` сохранены отдельно в `git-temporary-objects/`.
После этого Git сообщает garbage=0, проверка связности проходит.

Локальный архив: `~/workspace-archives/reachy-companion-2026-10-30/`.

- `worktree-before-cleanup.tar.gz`: состояние до очистки, включая локальные
  настройки; архив закрыт правами 600, каталог — 700.
- `tracked-before-cleanup.patch`, `index-before-cleanup.txt`,
  `status-before-cleanup.txt`: исходное состояние Git.
- `artifacts/`: 265 прежних корневых каталогов/предложений/сборок, сохранённых
  перемещением; точный список в `relocation.json`.
- `private/`: три неиспользуемых основным runtime локальных файла (`text-api.json`
  и пара S3 credential-файлов), закрытые правами 600.

Для выборочного восстановления перенесите `artifacts/<имя>` в исходный корень.
Для полного восстановления распаковывайте tar.gz сначала в отдельный каталог,
сверьте diff и только затем возвращайте нужные файлы. Не распаковывайте поверх
текущей версии вслепую. Локальные конфиги и `secrets/` остались на исходных путях.
Архив не переносится в Git и не нужен для сборки/тестов текущего checkout.

## Изменения

1. Все нужные модули, ресурсы, тесты и публичные инструкции включены в Git.
2. R42 manifest v11 фиксирует текущие 34 файла; старые входные provenance pins
   сохранены как история, без ложного объявления аппаратной приёмки.
3. Worker code identity включает девять ранее пропущенных существующих модулей;
   строгие проверки происхождения, SHA и точного состава не ослаблены.
4. Исторические fixtures сведены в `tests/fixtures/legacy/`; R15 восстановлен
   byte-for-byte, установленный prompt R52 заменён синтетическим.
5. Python 3.13 + `requirements/dev.lock`, dev extra и offline CI. Старые device
   lock-файлы и модельные зависимости не менялись.
6. README/START-HERE/STATUS согласованы; прежний README сохранён в `docs/history/`.
   Операционные журналы помечены историческими. Старые ссылки на перенесённые
   эксперименты имеют историческое значение, см. `coordination/README.md`.
7. Найден и исправлен reentrant deadlock обработки SIGTERM/SIGINT в двух
   autonomous session entrypoints. SignalStop ставит terminal signal flag без
   захвата Event lock, сохраняя обычный control STOP и прежний cleanup. Добавлены
   три проверки, включая реальный сигнал при занятом condition lock.
8. NumPy/FastAPI включены в dev lock для выполнения ранее пропускавшихся тестов.
   Устаревшая structural regression теперь учитывает существовавший nullable
   owner; отдельный behavioral test проверяет admission и прежние негативы.
9. Кэши Finder удалены; generated build/cache и локальные credentials исключены
   из Git/Docker context. Основной Agent, R42 и autonomous путь сохранены.

При побайтовом сравнении с tar.gz ни один существовавший runtime Python-файл
не потерян. Из прежних исходников изменены только `code_identity.py` и два
session entrypoints; добавлен `autonomous/signal_stop.py`. Код профиля R42
сохранён без изменений, обновлён его manifest. Локальные конфиги и token
побайтово совпадают с резервной копией.
