# Reachy Companion

Локальный проект автономного компаньона для Reachy Mini.

## Желаемое поведение

Робот постоянно вызывает LLM и самостоятельно выбирает, что делать. Обращение
человека — один из входов, а не условие запуска. Даже решение «ничего не делать»
принимается заново на следующей итерации. Бездействие допустимо, остановка цикла
из-за отсутствия собеседника — нет.

### Вход каждой итерации

- **Кэш чувств:** последние распознанные слова, уровень и изменения шума,
  изображение или описание сцены. У наблюдений есть источник, timestamp и TTL;
  устаревшие данные не выдаются за текущее восприятие.
- **Состояние робота и среды:** заряд, энергопотребление, нагрузка/сопротивление
  сервоприводов, текущее время, доступность сети и ping. Новые датчики, включая
  лидар, подключаются как дополнительные сигналы.
- **Контекст:** недавние решения, действия, результаты и незавершённые задачи.
- **Долговременная память.**
- **Личность:** характер и способ общения/мышления.
- **Принципы.**
- **Закреплённая память:** необязательная цель или задача. Робот может менять её,
  сохраняя причину изменения и timestamp, и знает, когда менял её последний раз.

Кэш отражает реальные изменения звуков, сцены, нагрузки и других сигналов,
включая тихий фон. Отсутствие речи не означает отсутствие входов. Неизвестные
показания остаются неизвестными; искусственный шум не подменяет наблюдения.

### Выход каждой итерации

- Общее действие: ждать, прислушаться, сконцентрироваться, подумать, отреагировать.
- Речь, если нужна.
- Движения, если нужны: взгляд по сторонам, внимание к звуку, жесты, танец.
- Вызовы функций: веб-поиск, фоновое рассуждение, shell-команды и другие инструменты.

Робот может спокойно стоять, решить осмотреться после шума или потанцевать под
мелодию. Выбор зависит от ощущений, контекста, памяти, личности, принципов и цели.
Движения и реакции частые и уместные; говорить или двигаться на каждом шаге
необязательно. STOP, privacy, права на инструменты и физические пределы имеют
приоритет над решениями модели.

### Непрерывность и асинхронность

Короткие итерации идут максимально часто в пределах вычислительного бюджета.
Одна итерация может состоять из нескольких подзапросов: сначала быстрая
классификация, затем содержательная реакция. Робот может сказать «хмм» или
«сейчас подумаю о…», начать движение и продолжить обработку в фоне.

Тяжёлые задачи не блокируют обычный цикл: новые наблюдения поступают, решения
уточняются, готовые результаты подключаются по мере завершения. Контекст хранит
компактное текущее состояние и изменения, заменяя устаревшие сведения вместо
бесконечного добавления почти одинаковых сообщений.

Пример последовательности:

1. Тихо: робот осматривается, изображение обрабатывается в фоне.
2. Появился звук: робот поворачивается к нему и запускает обработку аудио.
3. Обработка ещё идёт: робот продолжает реакцию и принимает новые наблюдения.
4. Результат готов: робот уточняет реакцию, например произносит «кажется, что-то
   упало» и делает жест. Уверенность формулировки соответствует наблюдениям.

Цель — непрерывное восприятие, обдумывание и готовность к реакции без ожидания
окончания всех задач на каждом шаге.

### Фоновые процессы

- Кэш чувств обновляется **часто**.
- Долговременная память обновляется **со средней частотой**.
- Личность и принципы обновляются **редко**.
- Логи постоянно отправляются через устойчивую локальную очередь в S3.
  Обработка на VPS формирует корректировки поведения, памяти, личности,
  принципов и мышления. Изменения версионируются и допускают откат;
  состав отправляемых данных учитывает privacy.

Измеряются задержки и очередь асинхронных задач. При превышении заданного
порога робот один раз явно сообщает, что запутался/перегрузился, прекращает
обычные реакции и новые выходы, ждёт завершения или отмены задач, объединяет
результаты и затем отвечает. STOP и ручное управление доступны и в этом режиме.

### Варианты вычислительной платформы

- Raspberry Pi: хаб, цикл решений, маршрутизация и управление.
- PC: LLM, STT, TTS, VLM и тяжёлые фоновые процессы.
- Лёгкая LLM около **0,6B**: классификация, быстрые фразы и действия.
- Основная LLM около **12B**: полноценные ответы и действия.
- Сильная онлайн-модель через платный API: редкий сложный фоновый анализ.
- Hermes Agent и OpenClaw — возможные основы агентного runtime.

Это варианты реализации; описание поведения не привязано к конкретному агенту
или набору моделей.

## Код

| Каталог | Содержимое |
|---|---|
| `src/reachy_companion/` | Agent, Hub, router, worker и CLI |
| `src/reachy_companion/autonomous/` | Цикл решений, состояние, память и адаптеры |

## Локальная разработка

Python 3.13; для JavaScript-теста панели — Node.js 22+.

```sh
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements/dev.lock
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python -m unittest discover -s tests
node tests/test_conversation_mode_page.cjs
.venv/bin/python -m build --no-isolation
```

Тесты исторических патчей используют Git-историю: нужен полный checkout.
Конфигурация создаётся из `config.example.json`; локальные настройки и секреты
не входят в Git. SSH-helper `scripts/factory_ssh.py` получает пароль из
`REACHY_FACTORY_SSH_PASSWORD`.
